# หน้าแรก — headline / tagline ให้เลือก (Feedback #2 — F5.1, D-17)

- **ที่มา:** เสียง 16:08–16:30 — "หน้าแรกขอดู 2 แบบ" · ข้อความชุดปัจจุบันคือของ Feedback #1 D-2 (`วางแพลน ไปเที่ยว / จดงบ / จบในที่เดียว.`)
- **กติกาที่ล็อกไว้ (Feedback #1 D-2):** พูดกับ *ใครก็ได้ กี่คนก็ได้ ที่ไหนก็ได้* · **ห้าม**ใช้คำว่า "กลุ่ม" "หมู่คณะ" "แก๊ง" ในหัวข้อ · ประโยคสั้น หักบรรทัดเอง ~10 ตัวอักษรต่อบรรทัด · ปิดท้ายด้วยจุด
- **สถานะ:** รอผู้ทดสอบเลือก 1 ชุด · ระหว่างรอ โค้ดแบบ A ใช้ **ชุด 1** และแบบ B ใช้ **ชุด 4** ไปก่อน (สลับได้ที่ตัวแปร `HEADLINE` ใน `components/marketing/landing-a.tsx` และ `landing-b.tsx`)

| ชุด | Headline (หักบรรทัดตามนี้) | Tagline | โน้ต |
|---|---|---|---|
| **1** | ทริปหน้า / เริ่มวางได้เลย / **วันนี้.** | จะไปคนเดียวหรือไปกันหลายคน รู้แค่วัน รู้แค่ตั๋ว หรือยังไม่รู้อะไรเลย — เริ่มจากตรงไหนก็ได้ AI ช่วยร่างแพลนรายวันพร้อมงบ แล้วจดค่าใช้จ่ายจริงจบในที่เดียว | ตรงกับสิ่งที่หน้า "สร้างทริป" ทำจริง (D-9) · "วันนี้" คือคำที่ knockout |
| **2** | วางแพลน / ไปเที่ยว / **จดงบ.** | แพลนรายวันจาก AI แก้ต่อได้ตามใจ ค่าใช้จ่ายจริงหารกันจบในทริป — ไปกี่คน ไปที่ไหนก็ได้ | ชุดเดิมของ Feedback #1 ตัด "จบในที่เดียว" ให้เหลือ 3 กริยาสั้น |
| **3** | ที่อยากไป / วันที่ว่าง / งบที่มี / **รวมเป็นทริป.** | ทุกอย่างที่ต้องตัดสินใจก่อนออกเดินทาง อยู่ในหน้าเดียว — ใครใส่อะไรก็เห็นเหมือนกัน แล้ว AI จัดเป็นแพลนรายวันให้ | เล่าตามลำดับที่ user ทำจริง (ต้นตอร่วม 1) |
| **4** | แพลนดี / ไม่ต้องมีคนคอย / **สรุปให้.** | ที่อยากไป วันว่าง บิลที่ยังไม่หาร — ROVE เก็บให้ในที่เดียวและร่างแพลนรายวันให้ ไม่มีใครต้องเป็นคนรวบรวมอีก | มาจาก pain point ในหน้า "แชทเลื่อนหาย" · เหมาะกับแบบ B ที่เล่าเรื่อง |
| **5** | เที่ยวให้ / ครบทุกคน / **ในแพลนเดียว.** | ใส่ที่ที่อยากไปได้ทุกคน AI จัดลงวันให้และบอกว่าของใครยังไม่เข้าแพลน — ไม่มีใครน้อยใจ ไม่มีใครต้องยอม | เน้น coverage board ซึ่งเป็นจุดขายที่ที่อื่นไม่มี · ระวัง "ทุกคน" ยังพูดถึงหลายคนอยู่ |

## ที่ตัดออก
- "วางแพลนเที่ยว กันทั้งกลุ่ม" — ล็อกภาพหมู่คณะ (Feedback #1 D-2)
- "ท่องเที่ยวไปโดยไม่มีเส้นทางตายตัว" (eyebrow เดิม) — อ่านแล้วเหมือนขายความสะเปะสะปะ ไม่ใช่การวางแผน · เปลี่ยน eyebrow เป็น "วางแพลนทริปกับ ROVE"

## วิธีเลือก
ส่งตารางนี้ให้ผู้ทดสอบ (หรือเปิดหน้าแรกทั้ง 2 แบบใน UAT แล้วสลับที่ปุ่มลอย) · เลือกได้ 1 ชุด หรือผสมหัวข้อชุดหนึ่งกับ tagline อีกชุดก็ได้ · ตอบกลับเป็นเลขชุด → แก้ที่ `HEADLINE` แล้วลบชุดที่เหลือออกจากไฟล์นี้
