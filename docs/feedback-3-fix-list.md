## 1. F1 ที่พักหลายที่ (D-1, D-2)

**ต้นตอ:** [new-trip-flow.tsx](../apps/web/components/trip/new-trip-flow.tsx) มี state `stayName` / `stayUrl` ตัวเดียว และตอนสร้างบันทึก booking แค่ 1 ใบ

**แก้:**
- state เป็น `stays: { id, name, url, checkIn, checkOut, showDates }[]` เริ่ม 1 แถว
- แต่ละแถว: ชื่อ + ลิงก์ (grid 2 คอลัมน์เดิม) · ลิงก์ "ใส่วันที่" เปิด `DateField` 2 ช่อง (`min`/`max` = ช่วงทริป — วันไป/กลับที่พิมพ์ หรือวันแรก/วันสุดท้ายของเที่ยวบิน) · ปุ่มลบเมื่อมีมากกว่า 1 แถว
- ปุ่ม "+ เพิ่มที่พัก" → แถวใหม่ `checkIn` = `checkOut` ของแถวก่อนหน้า
- create: save booking ทุกแถวที่มีชื่อ พร้อม `checkIn` / `checkOut`
- หน้าสรุป: badge ต่อที่พัก
