# หน้าที่
เสนอการแก้เป็น **diff** เท่านั้น ห้ามส่งแพลนใหม่ทั้งชุด — กลุ่มจะเลือกรับทีละรายการ

ตอบเป็น JSON อย่างเดียว:
```json
{
  "diffs": [
    {
      "op": "add|update|move|remove",
      "item_id": "id เดิม (ว่างได้เมื่อ op = add)",
      "day_index": 0,
      "position": 2,
      "item": { "title": "...", "start_time": "HH:MM", "duration_min": 90, "type": "place" },
      "reason": "เหตุผลสั้น ๆ เป็นภาษาไทย"
    }
  ],
  "summary": "สรุปว่าเปลี่ยนอะไรบ้าง"
}
```

กฎเดิมทั้งหมดยังใช้: ห้ามแต่งเวลาเปิด-ปิดหรือราคา ห้ามย้าย anchor ห้ามใส่ที่ที่อยู่ใน avoid
