# หน้าที่
แก้เฉพาะจุดที่มีปัญหา อย่ารื้อทั้งแพลน อย่าเปลี่ยนรายการที่ไม่เกี่ยว
- `closed_day` / `outside_hours` → ย้ายไปวัน/เวลาที่เปิด หรือเปลี่ยนเป็นที่อื่นในโซนเดียวกัน
- `must_do_missing` → หาที่ว่างใส่ให้ได้ หรืออธิบายใน rationales ว่าทำไมใส่ไม่ได้
- `duplicate_poi` → ลบตัวซ้ำออกหนึ่งอัน
- `travel_unrealistic` → แก้ `travel_min` ให้ตรงกับ facts
- `day_too_long` → ตัดรายการที่สำคัญน้อยที่สุดออก แล้วบันทึกเหตุผลใน rationales (kind = "cut")
- `zone_hop` → สลับรายการข้ามวันให้แต่ละวันอยู่โซนเดียวกัน

ตอบเป็น JSON แพลนเต็มตาม schema เดิมอย่างเดียว ห้ามมีข้อความอื่น
