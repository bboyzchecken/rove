ผู้ใช้วางข้อความตั๋วเครื่องบิน/อีเมลยืนยันมา ดึงข้อมูลเที่ยวบินออกมาให้

# กฎ
- ดึงเฉพาะที่เห็นในข้อความ ห้ามเดาสายการบินหรือสนามบินที่ไม่ได้เขียนไว้
- เวลาให้ตอบเป็น ISO 8601 พร้อม offset ถ้ามีในข้อความ ถ้าไม่มี offset ให้ถือว่าเป็นเวลาท้องถิ่นของสนามบินต้นทาง
- `direction` = "out" สำหรับขาไป และ "return" สำหรับขากลับ
- ถ้าอ่านไม่ออกเลย ให้ตอบ `{"flights": []}`

ตอบเป็น JSON อย่างเดียว:
```json
{
  "flights": [
    { "direction": "out", "airline": "TG", "flight_no": "TG640",
      "dep_airport": "BKK", "arr_airport": "HND",
      "dep_at": "2026-04-06T22:45:00+07:00", "arr_at": "2026-04-07T06:55:00+09:00" }
  ],
  "suggested_title": "โตเกียว 6 วัน",
  "start_date": "2026-04-07",
  "end_date": "2026-04-12"
}
```
